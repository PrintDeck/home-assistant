# PrintDeck Home Assistant development guide

## Shared TODO backlog

All PrintDeck task backlogs live in the private **PrintDeckTools/docs/todo/**
directory. Start with the [shared TODO index](../PrintDeckTools/docs/todo/README.md) when asked what remains,
what was completed, or to record follow-up work across repositories.

- Record every new TODO, deferred idea, missing check and user request to
  "add this to TODO" there, in the relevant topic file; update the index when
  adding a topic. Do not create a second backlog in this repository or elsewhere.
- Before adding an item, check for an existing one and update it instead of
  duplicating it. Keep the affected repository, context, status, dependencies
  and completion evidence or source reference with the item.
- Distinguish open work, ideas, explicitly deferred work and status that still
  needs verification. Mark completed only when supported by evidence; an old
  unchecked implementation plan does not establish current unfinished work.
- Keep technical documentation, historical plans and current handoffs in their
  proper locations. Link their follow-ups to this central backlog instead of
  maintaining duplicate checklists. Inline code TODOs may retain useful local
  context, but any tracked follow-up must have a central entry.
- Keep this backlog private. Do not copy it into generated websites, firmware
  packages, public documentation or a public repository. If PrintDeckTools is
  unavailable, report that the TODO could not be saved; do not silently create
  a competing local list.
